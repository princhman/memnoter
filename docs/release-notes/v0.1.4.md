# Memnoter v0.1.4

**IMPORTANT: Update every device before using tables, highlights, foldable
blocks, PDF quotes or drawings.** Builds before 0.1.4 delete content they do not
recognise when opening or syncing a note. Version 0.1.4 and later preserve that
content and open notes containing unsupported content read-only, with a prompt
to update. Updating one device does not protect a note opened by an older build
on another device.

## New

- Add tables and colored highlights to your notes.
- Hide examples and extra detail inside foldable blocks with their own title.
- Render Mermaid diagrams directly from code blocks.
- Keep PDFs alongside your notes. Quote selected text or an image region, then
  follow its source link back to the PDF page. Add highlights and annotations,
  and jump from a PDF quote marker back to the note.
- Create and edit drawings in notes, with PencilKit support on iPad.
- Import Obsidian notes and Anki `.apkg` decks.
- Organize modules into folders in the sidebar.

## Improved

- Navigate long notes with the Contents rail, section focus and reading highlight.
- Insert blocks from the right-click menu and enter math with KaTeX shorthand.
- Clearer toasts report imports and other actions. A beta notice makes it easier
  to send feedback.
- PDF reading, quote placement and returning to a note keep your place and cursor.
- Desktop navigation, editor actions and saved note views work more consistently.

## Fixed

- Notes containing content from a newer app version stay read-only instead of
  silently losing unsupported blocks, formatting or attributes.
- Fixed sidebar folder behavior and migration issues found during release testing.
- Fixed PDF scrolling and selection interactions, and improved quote navigation
  without recreating the note editor.

## iPhone & iPad

- Memnoter now runs on iPhone, with layouts for smaller screens and native navigation.
- Read PDFs beside notes on wide screens or over the note on compact screens,
  while preserving the open note and insertion cursor.
- Use Apple's native PDF text-selection menu for quoting and annotation actions.
- Draw with native ink on iPad, and keep drawings and PDF sources with synced notes.
- Improved sidebar folders, keyboard clearance and editor layout on iOS.

Desktop downloads are attached to the release. The iPhone and iPad app is
available through TestFlight.
